## Brand & Style
This design system defines a luxury automotive intelligence platform that bridges executive editorial presentation with high-performance telemetry and AI decision science. The aesthetic balances deep technical precision with bespoke automotive craftsmanship—evoking the cockpit of an ultra-high-end electric hypercar paired with an aerospace command deck.

The interface serves automotive executives, vehicle telemetry engineers, and fleet strategists. Interactions must feel instant, authoritative, and frictionless. Visual weight is established through controlled density: expansive negative space around macro-level insights, paired with surgical, high-density data readouts in detail panels.

The visual style blends modern technical minimalism with refined glassmorphism:
- **Atmospheric Depth:** Multi-tiered dark surfaces rooted in deep charcoal and carbon tones.
- **Precision Instrumentation:** Monospaced data tags, structural registration marks, and subtle mechanical alignment grids.
- **Translucent Optics:** Frosted glass panels layered with hair-thin borders to separate telemetry streams without adding visual mass.

## Colors
The palette is built upon a deep optical foundation designed to maximize legibility and minimize eye fatigue during high-focus telemetry analysis.

### Surface Palette
- **Canvas / Void:** `#06080B` (pure base background)
- **Neutral Base:** `#0B0E14` (primary surface neutral)
- **Surface Elevation 1 (Card/Container):** `#111622` (subtle graphite base, 60%–80% opacity when glassmorphic)
- **Surface Elevation 2 (Floating Layer):** `#182030`
- **Hairline Borders:** `rgba(255, 255, 255, 0.08)` to `rgba(0, 242, 254, 0.2)` for active states

### Semantic & Accent Spectrum
- **Electric Cyan (`#00F2FE`):** Primary accent. Used for active states, key data trends, focus rings, and primary interactive vectors.
- **Hyper Violet (`#8A2BE2`):** Secondary accent. Signifies automated AI inference, neural processing indicators, and predictive vectors.
- **High-Confidence Emerald (`#10B981`):** Tertiary accent. Reserved for optimal component health, safe operational margins, and high AI model confidence (>95%).
- **Warning Amber (`#F59E0B`):** Telemetry deviations, moderate latency, sensor recalibration advisories.
- **Critical Crimson (`#EF4444`):** Threshold breaches, collision metrics, emergency operational overrides.

## Typography
The typographic architecture creates a direct tension between human-curated editorial elegance and machine-generated data streams.

- **Editorial Headlines & Narratives (Plus Jakarta Sans):** Applied with tight tracking and balanced weights. Used for executive summaries, chassis model identifiers, and high-level vehicle posture metrics.
- **Instrument Readouts & Telemetry (JetBrains Mono):** Reserved for coordinate tracks, dynamic torque outputs, AI confidence metrics, status pills, and system logs. The tabular spacing ensures fluctuating numbers never cause layout jitter.
- **Case Conventions:** High-level status tags, coordinate metadata, and axis labels always render in uppercase via `label-caps`.

## Layout & Spacing
The layout operates on a flexible 12-column grid system bounded by fixed gutter constraints to mimic engineered instrument clusters.

- **Grid Alignment:**
  - **Desktop (>=1280px):** 12-column grid with `margin` (2.5rem / 40px) and `gutter` (1.5rem / 24px).
  - **Tablet (768px - 1279px):** 8-column layout, `gutter` drops to 1rem (16px), margins adjust to 1.5rem (24px).
  - **Mobile (<768px):** 4-column layout, `gutter-sm` (0.75rem / 12px), `margin-mobile` (1rem / 16px). High-density readouts compress into scrollable horizontal telemetry ribbons.

- **Subtle Grid & Registration Marks:** Canvas backgrounds may implement a faint mechanical background grid (`rgba(255, 255, 255, 0.02)` on 32px intervals) with hair-thin corner crosses (`+`) defining major section coordinates.
- **Component Flow:** Internal card padding adheres strictly to `space-md` (16px) for compact data modules and `space-lg` (24px) for expansive analytical charts.

## Elevation & Depth
Elevation is constructed via optical translucency and layered light refraction rather than standard heavy drop shadows.

- **Level 0 (Chassis Ground):** The canvas at `#06080B`. Unlit, matte, non-interactive.
- **Level 1 (Telemetry Panels):** Frosted glass surface using `rgba(17, 22, 34, 0.75)` with `backdrop-filter: blur(16px)` and a 1px border of `rgba(255, 255, 255, 0.07)`.
- **Level 2 (Active Inspections / Modals):** Elevated glass using `rgba(24, 32, 48, 0.85)` with `backdrop-filter: blur(24px)`. Rim lighting applies a top-edge linear gradient highlight (`rgba(255, 255, 255, 0.15)` fading to `rgba(255, 255, 255, 0)`).
- **Glow & Energy Radiance:** Interactive components utilize ambient colored glows instead of black shadows:
  - Primary active focus: `0 0 20px rgba(0, 242, 254, 0.25)`
  - AI dynamic inference: `0 0 24px rgba(138, 43, 226, 0.2)`
  - High confidence anchor: `0 0 16px rgba(16, 185, 129, 0.2)`

## Shapes
To preserve an aerodynamic, precision-machined aesthetic, the design system utilizes restrained, controlled corner radii. Organic, playful pill-shapes are restricted solely to inline status tags.

- **Level 1 (Soft Geometry):**
  - Standard cards, interactive controls, inputs, and flyouts utilize `0.25rem` (4px) to `0.375rem` (6px) corner rounding.
  - Modals and primary viewport boundaries leverage `rounded-lg` (0.5rem / 8px).
- **Data Badges:** Telemetry micro-badges and live state indicators may use 2px radii or full 9999px pills depending on role (metrics use 2px chamfered corners; live operational states use pills).
- **Hair-Thin Linework:** All structural bounding lines maintain an uncompromising 1px width.

## Components

### Buttons & Interactive Triggers
- **Primary Kinetic:** Cyan fill (`#00F2FE`) with black text (`#06080B`), font weight 600. Minimal ambient cyan glow on hover (`0 0 16px rgba(0, 242, 254, 0.4)`).
- **Secondary Ghost:** Transparent fill, 1px border of `rgba(255, 255, 255, 0.15)`, text in `#F8FAFC`. On hover, border shifts to `#00F2FE` and background gains `rgba(0, 242, 254, 0.05)`.
- **AI Action Trigger:** Hyper Violet outline (`#8A2BE2`) with subtle radial gradient fill. JetBrains Mono uppercase command text.

### Badges & Telemetry Chips
- **Monospace Data Badges:** JetBrains Mono (`label-caps`), 4px vertical / 8px horizontal padding.
- **Confidence Rating:** High-confidence renders with an emerald dot (`#10B981`), emerald text, and `rgba(16, 185, 129, 0.1)` fill.
- **Telemetry Deviation:** Crimson or Amber border with matching monospaced numerical deltas (`+1.42%`, `CRIT_TEMP`).

### Cards & Analytical Panels
- Base container built on Level 1 elevation with `backdrop-filter: blur(16px)`.
- Header elements feature an editorial display label paired with a secondary monospaced coordinate/timestamp identifier in `label-caps`.
- Optional corner notches or registration marks in the upper-right corner to indicate live sensor connectivity.

### Input Fields & Controls
- Background: `rgba(6, 8, 11, 0.6)`. Hairline border of `rgba(255, 255, 255, 0.1)`.
- Active focus state: Border transitions to `#00F2FE` with an instantaneous subtle outer glow. Text displays in crisp white with placeholder values in subdued graphite (`rgba(255, 255, 255, 0.3)`).

### Selection (Checkboxes & Radios)
- Geometric, square checkboxes with 2px corner radius. Radio indicators use concentric rings with cyan dot center.
- Unchecked: 1px border in `rgba(255, 255, 255, 0.2)`, background transparent.
- Checked: `#00F2FE` border and active glow with pure black vector icon mark.

### Domain-Specific Components
- **Chassis Telemetry Visualizer:** Dual-layer HUD element combining high-resolution 3D vehicle geometry overlays with real-time monospaced vector points.
- **AI Decision Tree Nodes:** Semi-transparent violet-bordered connectors linking predictive autonomous decisions to real-time confidence scores.
